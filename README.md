# 전생록 前生錄

**내가 조선의 모시 장수였다면, 흠이 생긴 옷감을 손님에게 먼저 펼쳐 보였을까?**

전생록은 얼굴과 성격, 오늘의 삶을 단서로 AI가 한 사람의 전생을 역사 단편으로 쓰는 한국어 웹 서비스입니다. 결과 카드를 열면 먼저 시대와 직업이 드러납니다. 갈림길에서 지금의 내가 고를 답을 눌러 보면, 이야기 속 인물이 실제로 고른 쪽과 그 뒤에 벌어진 일을 읽을 수 있습니다.

## 한 편의 전생이 만들어지는 과정

1. 정면 얼굴 사진, 여섯 자리 생년월일, 성씨와 성격, 현재 직업을 입력합니다. 본관을 덧붙일 수 있고, 순자산과 집안 형편은 구간 선택 또는 비공개가 가능합니다.
2. 구석기 강가부터 현대의 일터까지 30개 배경 중 태어나기 전의 시대와 장소를 고릅니다. AI가 입력한 습관을 그 시대의 행동으로 옮기고, 그 선택 때문에 이득을 본 사람이나 대가를 치른 사람을 이야기 속에 담습니다.
3. 카드에서 얼굴의 어느 특징과 어떤 습관을 풀이에 썼는지 확인합니다. 오늘의 직업·재산·집안 형편은 ‘이번 생에 돌아온 복’으로 풀어냅니다. 역사 자료를 사용한 장면에는 출처가 함께 나옵니다.

## 사진과 개인정보

얼굴 특징점은 브라우저에서 측정하며 원본 사진과 생년월일 여섯 자리는 서버로 전송하지 않습니다. AI에는 얼굴 비율을 설명한 문장과 태어난 계절 등 집필에 쓰이는 단서가 전달됩니다. 개인 결과는 해당 브라우저 탭에서 읽으며, 공개 서고에는 별도로 쓴 단편이 실립니다. [개인정보와 광고 안내](https://jeonsaengrok.com/privacy.html)

## 프로젝트 구성

브라우저 화면과 공개 단편은 `web/`, AI 집필과 이용 한도 처리는 `worker/`, D1 데이터베이스 스키마 변경은 `drizzle/`에 있습니다. Node.js 22.13 이상에서 `npm ci` 후 `npm test`로 테스트를 실행할 수 있습니다.
